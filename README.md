# RPGGameAnime

Рабочий проект MMORPG. Целевая клиентская платформа — **Android-приложение в формате APK**. Сейчас собирается устанавливаемый APK-прототип: он упаковывает кликабельные демонстрационные экраны интерфейса и работает офлайн. Это не полноценная игра: сервер, игровой прогресс и боевые механики пока не реализованы.

Дизайн игры ведётся в четырёх документах:

1. [Сценарий игры](docs/SCENARIO.md) — мир, основной сюжет и сюжетные линии.
2. [Механики игры](docs/MECHANICS.md) — города, экономика, классы, торговля и игровые системы.
3. [Классы игроков и NPC](docs/CLASSES_AND_NPCS.md) — боевые классы, профессии, NPC и их истории.
4. [Интерфейс мобильного приложения](docs/INTERFACE.md) — внешний вид и структура экранов будущего APK.

Формат изображения игрового мира и конкретный боевой цикл пока не зафиксированы. [Открыть кликабельный веб-прототип интерфейса](ui-prototype/index.html) или посмотреть [инструкцию по сборке Android APK](android-prototype/README.md). Автоматическая сборка публикует устанавливаемый debug APK как artifact GitHub Actions.
