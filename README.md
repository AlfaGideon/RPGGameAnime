# RPGGameAnime

Рабочий проект MMORPG. Дизайн игры ведётся в трёх отдельных документах:

1. [Сценарий игры](docs/SCENARIO.md) — мир, основной сюжет и сюжетные линии.
2. [Механики игры](docs/MECHANICS.md) — города, экономика, производство, торговля и игровые системы.
3. [Классы игроков и NPC](docs/CLASSES_AND_NPCS.md) — роли классов, классовые истории и персонажи.

Все три документа — рабочие концепции. Формат отображения и управления игрой пока не выбран.
