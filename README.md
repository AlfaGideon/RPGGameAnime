# RPGGameAnime

Рабочий проект MMORPG. Целевая клиентская платформа — **Android-приложение в формате APK**. Устанавливаемый APK-прототип упаковывает кликабельные экраны, карту мира и демо-настройки. В профиле можно выбрать портрет из встроенной галереи игры; загрузка своих фото не предусмотрена. У приложения есть фирменная заставка и значок «Эхо Астры». Сам интерфейс работает офлайн; проверка обновлений GitHub требует интернет. Это не полноценная игра: сервер, игровой прогресс и боевые механики пока не реализованы.

Дизайн игры ведётся в четырёх документах:

1. [Сценарий игры](docs/SCENARIO.md) — мир, основной сюжет и сюжетные линии.
2. [Механики игры](docs/MECHANICS.md) — города, экономика, классы, торговля и игровые системы.
3. [Классы игроков и NPC](docs/CLASSES_AND_NPCS.md) — боевые классы, профессии, NPC и их истории.
4. [Интерфейс мобильного приложения](docs/INTERFACE.md) — внешний вид и структура экранов будущего APK.

Формат изображения игрового мира и конкретный боевой цикл пока не зафиксированы. [Открыть кликабельный веб-прототип интерфейса](ui-prototype/index.html) или посмотреть [инструкцию по сборке Android APK](android-prototype/README.md). CI проверяет и публикует устанавливаемый debug APK; собранный файл текущего прототипа хранится в `apk-output/Echo-Astra-UI-Prototype.apk`.
