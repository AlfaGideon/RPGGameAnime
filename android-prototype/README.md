# Android APK-прототип

Это небольшой нативный Android-контейнер для существующего кликабельного интерфейса в `../ui-prototype/`. Приложение открывает `index.html` и связанные CSS/JS-файлы из APK assets в `WebView`; копия файлов не требуется. Поэтому демонстрация работает офлайн и не нуждается в разрешении на интернет.

## Что входит в прототип

- Вертикальная Android-оболочка с названием и значком приложения.
- Стартовый экран, создание персонажа, выбор боевого класса и профессии, пролог и остальные кликабельные демо-экраны из веб-макета.
- Демонстрационные роли пяти боевых классов и переключение профилей интерфейса.
- Никаких игровых серверов, аккаунтов, сохранения прогресса или реальных боевых действий.

## Сборка APK локально

Нужны JDK 17, Android SDK (Android 35 и Build Tools 35.0.0) и Gradle 8.9. Из корня проекта:

```bash
cd android-prototype
gradle --no-daemon :app:assembleDebug
```

Готовый устанавливаемый debug APK появится здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```

На подключённое Android-устройство его можно установить командой `adb install -r app/build/outputs/apk/debug/app-debug.apk`. Для ручной установки скачанного файла Android может попросить разрешить установку APK из выбранного приложения-файлового менеджера.

## Сборка через GitHub Actions

Workflow [Build Android UI prototype APK](../.github/workflows/android-prototype.yml) запускается после изменения `android-prototype/` или `ui-prototype/`, а также вручную через `workflow_dispatch`. Каждая успешная сборка проверяет подпись APK и наличие локальных HTML/CSS/JS-экранов, затем публикует artifact **Echo-Astra-UI-Prototype-debug-APK**.

При push изменений в текущую Arena-ветку проверенный APK автоматически сохраняется в `apk-output/Echo-Astra-UI-Prototype.apk`.

Debug APK предназначен для прототипирования и ручного тестирования; это не релизная сборка для публикации в магазине.
